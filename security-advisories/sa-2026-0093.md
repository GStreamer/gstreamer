## Details

An out-of-bounds read vulnerability in the MXF demuxer in gst-plugins-bad.
When looking up sample positions in a file's index table, the demuxer uses a
per-track index into the index table's delta lookup table, as used for tracks
interleaved in a shared container. If the position of a track in that lookup
table is unknown or could not be determined, a negative value is stored, and
some lookup code paths used this value as an array index without checking that
it was valid.

This affects all versions of gst-plugins-bad before 1.28.9.

## Impact

A malicious third party could trigger an out-of-bounds heap read by providing
a crafted MXF file. This can result in an application crash or denial of
service, and possibly information disclosure.

## Solution

The gst-plugins-bad 1.28.9 release addresses the issue. People using older
versions of GStreamer should apply the patch and recompile.
