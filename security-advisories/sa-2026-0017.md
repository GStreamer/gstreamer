## Details

Integer overflow in the H.266/VVC video parser when handling malformed H.266 streams. The overflow occurs during parsing of profile, tier, and level fields, which can lead to a stack-based buffer overflow.

## Impact

A malicious third party could trigger a crash in the application, resulting in denial of service, or possibly execute arbitrary code when processing malicious H.266 media files.

## Solution

The gst-plugins-bad 1.28.2 release addresses the issue. People using older versions of GStreamer should apply the patch and recompile.
